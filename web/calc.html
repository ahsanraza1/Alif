Reference

3. Arithmetic

Operators are ASCII. Keywords for and / or / not are Urdu.

TokenMeaning
+ - * / % add, subtract, multiply, divide, remainder. / and % are unsigned, like the VM.
== != < > <= >= compare; the result is 0 or 1
اورand (short-circuit: stops on first zero)
یاor (short-circuit: stops on first nonzero)
نہیںnot (zero becomes 1, nonzero becomes 0)
( )group an expression

Assignment = is only in a declaration or a statement, not inside a larger expression.

Order

From bind-tightest to loosest:

  1. unary نہیں, unary +, unary -
  2. * / %
  3. + -
  4. comparisons
  5. اور
  6. یا
عدد جواب = (الف + ب) * 2؛

Numbers

A literal in v1 must fit in a 16-bit immediate: 0 to 65535. You may write ASCII digits 12 or Urdu digits ۱۲. Do not mix them in one number (1 then ۲ is illegal).

Divide by zero stops the VM (FAULT_DIV0).

Unary minus

عدد ن = -3؛

(The compiler uses the VM’s negate instruction. The digits themselves stay in 0..65535.)
