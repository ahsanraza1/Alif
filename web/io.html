5. Print and read

Print

لکھو writes an integer in decimal, then a newline. The expression may be a name or any other expression.

لکھو الف + ب؛
لکھو 1؛

There are no strings in v1. You cannot print a sentence, only numbers.

Read

پڑھو stores into a name that already exists:

عدد ن = 0؛
پڑھو ن؛

Honest limit: version 1 reads one byte from VM port 0 and zero-extends it into the variable. It is not “type a decimal number and press Enter.” A later language version can define that. For class examples, prefer لکھو and literals.

    لکھو ن؛
