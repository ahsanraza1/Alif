6. How to run

From the ALIF project, run build.bat once. That compiles the three tools and copies them into a folder named ship (not stored in git). You can copy ship to another machine.

The easy way

Put your source next to the tools or pass a path. The file name must end in .alif.

ship\run.bat add.alif

run.bat only calls, in order:

  1. alifc.exe — .alif to .afb
  2. afas.exe — .afb to .afbin
  3. alif.exe — run the image

It writes add.afb and add.afbin beside add.alif, then prints whatever لکھو produced.

The three tools by hand

alifc.exe add.alif
afas.exe add.afb
alif.exe add.afbin

Each program refuses the wrong suffix. The VM never reads Urdu source. The assembler never reads .alif.

How to type source

Save .alif as UTF-8 in any ordinary editor. Urdu letters must be real Unicode, not ?. A UTF-8 BOM is allowed.

Do not open an old AF8-byte file in a UTF-8 editor and save. That replaces letters with U+FFFD and the program is lost. If that happens, type the program again.

English editors often show Urdu left-aligned. The compiler does not care. This tutorial shows samples on the right so you can read them as Urdu.
