Reference

2. Names

Version 1 has one type: a 32-bit integer. The keyword عدد introduces a name. You must give it a value at once.

عدد الف = 2؛

Later you may assign again, without عدد:

الف = الف + 1؛

A name you never declared is an error. Declaring the same name twice is an error.

What a name looks like

Start with an Urdu letter. Then letters or digits (ASCII or Urdu digits). Keywords cannot be names.

GoodNotes
الفsuggested short name
بone letter
جوابresult
نoften a counter

Where values live

The compiler keeps variables in the VM’s RAM (one word each), not in the eight named registers. You can have many names; the limit is a few hundred bytes of variable space, not eight.

True and false

سچ is the integer 1. جھوٹ is 0. اگر and جبتک treat any nonzero value as true.

عدد پرچم = سچ؛
