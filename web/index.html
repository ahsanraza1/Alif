Welcome

علیف (Alif) version 1 is a small programming language written in Urdu. You type a .alif file in a text editor (UTF-8), then a compiler turns it into assembly, an assembler turns that into a machine image, and a virtual machine runs it.

.alif   Urdu source     (you write this)
  |
  |  alifc
  v
.afb    assembly        (ASCII)
  |
  |  afas
  v
.afbin  machine image
  |
  |  alif.exe
  v
        the VM prints numbers

The three tools stay separate. A small script run.bat in the ship folder calls them in that order so you do not have to.

What v1 can do

One type: a 32-bit integer. You can:

  • declare names with عدد and assign with =
  • add, subtract, multiply, divide, remainder
  • compare with == != < > <= >=
  • branch with اگر / ورنہ
  • loop with جبتک
  • print a number with لکھو
  • read one input byte with پڑھو

There are no functions, arrays, or strings yet. That is on purpose. Finish these pages, then write small programs.

A taste

This program prints 8:

شروع
عدد الف = 2؛
عدد ب = 6؛
عدد جواب = الف + ب؛
لکھو جواب؛
ختم

Keywords and names are Urdu. Operators, digits here, and braces are ASCII. Statements end with the Urdu semicolon ؛ (ASCII ; is also allowed). This handbook shows Urdu samples right-to-left. Many English editors still show the same bytes left-aligned; the file is still correct.
