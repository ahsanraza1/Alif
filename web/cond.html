Reference

4. If and while

Blocks use ASCII braces { }. The condition is an expression. Nonzero is true.

If / else

اگر … optional ورنہ …

شروع
عدد ن = 3؛
اگر ن > 0 {
    لکھو ن؛
} ورنہ {
    لکھو 0؛
}
ختم

This prints 3. You may omit ورنہ and its block.

While

جبتک is one word. Do not write a space inside it.

شروع
عدد ن = 3؛
جبتک ن > 0 {
    لکھو ن؛
    ن = ن - 1؛
}
ختم

This prints three lines: 3, then 2, then 1.

There is no break or continue in v1. Change the condition or the counter so the loop can end. A loop that never becomes false will hit the VM step cap and fault.

A combined test

اگر ن > 0 اور ن < 10 {
    لکھو ن؛
}

اور does not evaluate the right side if the left is already zero. یا does not evaluate the right side if the left is already nonzero.
