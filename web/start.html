1. First program

Every علیف program is one block:

شروع
    … statements …
ختم

شروع means the program begins. ختم means it ends. The compiler turns the end into a halt. Nothing but spaces or // comments may follow ختم.

Save this as add.alif (UTF-8). Then run it with the tools in lesson 6. It prints 8.

شروع
عدد الف = 2؛
عدد ب = 6؛
عدد جواب = الف + ب؛
لکھو جواب؛
ختم

Line by line

LineMeaning
شروع Start of the program.
عدد الف = 2؛ Make an integer named الف and put 2 in it.
عدد ب = 6؛ Make ب and put 6 in it.
عدد جواب = الف + ب؛ Make جواب and store the sum.
لکھو جواب؛ Print that number, then a newline.
ختم Stop.

Semicolon

Declarations, assignments, print, and read end with ؛ (Urdu semicolon). ASCII ; is accepted too. اگر / جبتک do not use a semicolon after the { } block.

Spaces and comments

Blank lines and spaces are ignored. A comment is ASCII // to the end of the line.

شروع
// two plus six
عدد الف = 2؛
ختم

Do not put harakat (zabar, zer, pesh) on letters. Version 1 rejects them.
